## ✨ ویژگی‌های برجسته پنل دیزاینو وی پی ان

- 🎨 **طراحی گرافیکی فوق‌العاده مدرن (Ultra Dark & Light Glassmorphism):**
  - دارای دو تم **تیره (Dark Mode)** و **روشن (Light Mode)** با قابلیت سوئیچ آنی.
  - کنتراست بالا، خوانایی کامل متون، پالت سورمه‌ای/نیلی/سیان بر پایه استاندارد مدرن Sanaei / Marzban / 3X-UI.
  - ۱۰۰٪ رسپانسیو برای گوشی‌های هوشمند، تبلت و کامپیوتر.
- 🔑 **راه‌اندازی اولیه و امنیت بالا (First-Time Setup Wizard):**
  - تعیین نام کاربری و رمز عبور ادمین در اولین باز کردن پنل قبل از ورود.
  - پنل کاملاً خام و تمیز بدون کاربران نمونه اولیه.
- ⚡ **پشتیبانی از پروتکل‌های متنوع با پینگ واقعی (پورت 443):**
  - **VLESS-WS (WebSocket + TLS)**
  - **VLESS-gRPC (gRPC + TLS)**
  - **Trojan-WS (Trojan WebSocket + TLS)**
  - تمام کانفیگ‌ها بر روی پورت **443 TLS** صادر شده و پینگ سبز واقعی (مثلاً ۱۲۰ms) در نرم‌افزارهای v2ray ارائه می‌دهند.
- 🌐 **اسکنر و مدیریت آی‌پی‌های تمیز (Clean IP Scanner):**
  - لیست آی‌پی‌های تمیز کلادفلر جهت اتصال آسان در اپراتورهای مختلف (همراه اول، ایرانسل، رایتل و شاتل).
  - امکان اعمال آی‌پی/دامنه تمیز اختصاصی روی تمام کانفیگ‌های کاربران با یک کلیک.
- 🤖 **یکپارچه‌سازی با ربات تلگرام (Telegram Bot):**
  - دریافت اطلاعات کاربر و لینک ساب از طریق ربات.
  - ارسال اعلان خودکار به ادمین در تلگرام هنگام ساخت کاربر جدید یا پایان اعتبار/حجم.
- 📱 **صفحه سابسکریپشن هوشمند (`/sub/:uuid`):**
  - نمایش صفحه گرافیکی و زیبای کاربر در مرورگر همراه با **کد QR کارآمد و آفلاین**.
  - ارائه مستقیم کدهای خروجی **Base64** خالص به نرم‌افزارهای VPN جهت جلوگیری از ارورهای پارس.
  - پشتیبانی از هدرهای استاندارد `Subscription-Userinfo` جهت نمایش حجم مصرفی در بالای نرم‌افزارهایی مانند v2rayN.
- 🔍 **فیلتر و جستجوی آنی کاربران:**
  - جستجوی سریع بر اساس نام یا UUID و فیلتر بر اساس وضعیت (فعال، منقضی، غیرفعال).

## 🚀 راهنمای سریع استقرار روی پلتفرم Railway (توصیه شده)

استقرار پنل دیزاینو روی پلتفرم **Railway** بسیار آسان است و نیازی به سرور اختصاصی یا خرید VPS ندارد.

### مراحل نصب:

1. **کلون یا فورک پروژه در گیت‌هاب:**
   کد پروژه را در حساب گیت‌هاب (GitHub) خود Fork کنید.

2. **ایجاد پروژه جدید در Railway:**
   - وارد حساب کاربری خود در [Railway.app](https://railway.app) شوید.
   - روی دکمه **New Project** کلیک کرده و گزینه **Deploy from GitHub repo** را انتخاب کنید.
   - ریپوزیتوری فورک‌شده پروژه‌تان را انتخاب کنید.

3. **تنظیم Volume ماندگار (Persistent Data Storage):**
   - برای جلوگیری از پاک شدن داده‌های کاربران پس از ری‌استارت، در داشبورد سرویس Railway به زبانه **Volumes** بروید.
   - یک Volume جدید با مسیر نصب (Mount Path) زیر ایجاد کنید:
     ```env
     /app/data
     ```

4. **تنظیم متغیرهای محیطی (Variables):**
   در زبانه **Variables** متغیرهای زیر را ثبت کنید:
   ```env
   PORT=8080
   DATA_DIR=/app/data
   SINGBOX_BIN=/app/sing-box
   ```

5. **دپلوی و اتصال دامنه:**
   - پلتفرم Railway به صورت خودکار پروژه را بر اساس `Dockerfile` می‌سازد.
   - در زبانه **Settings** بخش **Networking**، روی **Generate Domain** کلیک کنید تا یک دامنه رایگان HTTPS (مانند `dizyno-production.up.railway.app`) به پروژه تخصیص داده شود.
   - آدرس دامنه خود را در مرورگر باز کنید و فرآیند راه‌اندازی اولیه را انجام دهید!

## 💻 راهنمای اجرا در محیط توسعه محلی (Local Development)

برای تست پروژه روی سیستم شخصی (ویندوز / لینوکس / مک):

### پیش‌نیازها:
- نصب بودن **Node.js (نسخه 18 یا بالاتر)**
- نصب بودن **Git**

### مراحل اجرا:

1. **کلون کردن ریپوزیتوری:**
   ```bash
   git clone https://github.com/your-username/VPN_PANEL.git
   cd VPN_PANEL
   ```

2. **نصب وابستگی‌ها:**
   ```bash
   npm install
   ```

3. **اجرای سرور:**
   ```bash
   npm start
   ```
   سرور روی آدرس `http://localhost:8080` اجرا می‌شود.

## 📲 نحوه استفاده کاربران در نرم‌افزارهای VPN

کاربران می‌توانند لینک سابسکریپشن اختصاصی خود را در نرم‌افزارهای زیر وارد کنند:

### 📱 اندروید (Android)
- **v2rayNG:** دکمه `+` -> گزینه **Import subscription** -> جایگذاری لینک ساب -> دکمه **Update subscription**.
- **NekoBox / Sing-box / Hiddify:** اضافه کردن Group یا Subscription با نوع Auto Update.

### 🍎 آیفون / آی‌او‌اس (iOS)
- **Shadowrocket:** دکمه `+` -> انتخاب Type روی **Subscribe** -> وارد کردن URL لینک ساب.
- **Streisand / Stash / Quantumult X:** افزودن لینک سابسکریپشن و آپدیت آن.

### 💻 ویندوز (Windows)
- **v2rayN:** منوی **Subscription Group** -> گزینه **Subscription Group setting** -> دکمه **Add** -> وارد کردن لینک ساب -> کلیک روی دکمه **Update subscription (without proxy)**.

## 🛡️ امنیت و نکات نگهداری

1. در اولین راه‌اندازی، حتماً یک **کلمه عبور قوی** برای حساب مدیریتی ادمین انتخاب کنید.
2. همیشه مطمئن شوید که متغیر محیطی `DATA_DIR=/app/data` به یک Volume ماندگار متصل باشد تا اطلاعات کاربران در دپلوی‌های بعدی حفظ شود.
3. در صورت نیاز به تغییر پورت‌ها یا رمز عبور Trojan، می‌توانید از مودال **تنظیمات پنل** استفاده کنید.
